# Fast Media Player

A lightweight local **audio & video** player that runs in your browser. Files stay on your device — nothing is uploaded.

## Features

- Open or drag-and-drop local audio and video files
- Playlist queue with remove / jump-to-track
- Play, pause, seek, volume, mute, and playback speed
- Keyboard shortcuts for fast control
- Bundled sample clip to try instantly
- Private-by-default: playback uses local object URLs only

## Quick start

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Shortcuts

| Key | Action |
| --- | --- |
| `Space` / `K` | Play / pause |
| `←` / `→` | Seek ±5s |
| `↑` / `↓` | Volume |
| `M` | Mute |
| `N` / `P` | Next / previous |
